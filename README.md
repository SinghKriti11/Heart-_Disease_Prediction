# ❤️ Heart Disease Prediction using Machine Learning

A Machine Learning project that predicts the likelihood of heart disease using patient medical attributes and classification algorithms. This project focuses on data preprocessing, exploratory data analysis, model training, evaluation, and predictive system development using Logistic Regression.

---

# 📌 Project Overview

Heart disease is one of the major causes of death worldwide. Early prediction can help healthcare professionals take preventive measures and provide better treatment.

This project aims to build a machine learning model capable of predicting heart disease based on various health parameters.

The project includes:
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Model training and evaluation
- Predictive system development
- Accuracy analysis
